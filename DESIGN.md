# Ajaia Docs — Design System (`DESIGN.md`)

- **Direction:** Minimal Craft Floating Canvas (Excalidraw transparent floating header + `sheif.org` color scheme + Rauno tactile micro-interactions).
- **Palette (adapted from `sheif.org`):**
  - `--bg-desk`: `#F5F5F5` (Light) / `#1F1F1F` (Dark)
  - `--bg-paper`: `#FFFFFF` (Light) / `#262626` (Dark)
  - `--bg-island`: `rgba(255,255,255,0.92)` (Light) / `rgba(38,38,38,0.92)` (Dark)
  - `--bg-subtle`: `#EDEDEB` (Light) / `#323232` (Dark)
  - `--border-hairline`: `rgba(67,67,67,0.16)` (Light) / `rgba(245,245,245,0.14)` (Dark)
  - `--ink`: `#1F1F1F` (Light) / `#F5F5F5` (Dark)
  - `--ink-muted`: `#5E5E5E` (Light) / `#B6B3AC` (Dark)
  - `--accent`: `#C93E0D` (Light CTA, >=5.2:1 white text) / `#E8501A` (`sheif-crimson` ring & Dark accent)
- **Typography:** `Inter` (`tabular-nums` for word counts/timestamps; `16px` body, `1.68` line-height, `65-72ch` measure).
- **Concentric Radii:** Outer island `16px` (`6px` padding) -> inner button `10px`.
- **Copy Discipline:** Headings, subheadings, labels, and status pills only; zero eyebrow pills, zero body blurbs, zero em dashes.
